# Changelog

## [2026-09-28] - trip/index.html 어르신 시인성 최적화 모던 클린 테마 적용

### 요약
뉴모피즘의 낮은 명도 대비와 밋밋함을 개선하여, 어르신 및 온 가족이 야외에서도 한눈에 읽기 쉬운 화사하고 또렷한 모던 클린(High-Contrast) 테마로 리디자인.

### 변경 내역
- **가독성 & 타이포그래피:** 기본 폰트 크기 `16px` 및 헤딩/본문 스케일 대폭 확대, 행간 1.6 확장.
- **색상 대비 강화:** 
  - 메인 텍스트를 `#0f172a` (딥 챠콜 네이비)로 변경하여 명도 대비율 극대화.
  - 카드를 순백색(`#ffffff`)에 1px 클린 보더(`#e2e8f0`) 및 부드러운 그림자로 마감.
- **조작 편의성(터치 UX):** 탭 네비게이션 버튼과 하단 링크 복사 버튼의 터치 패딩 확대 및 활성 상태 솔리드 블루 시각 피드백 부여.

```diff
- --bg-color: #e6ecf4;
- --text-main: #1e293b;
- --text-muted: #64748b;
+ --bg-color: #f1f5f9;
+ --card-bg: #ffffff;
+ --card-border: #e2e8f0;
+ --text-main: #0f172a;
+ --text-body: #1e293b;
+ --text-muted: #475569;
+ --primary: #2563eb;
```
