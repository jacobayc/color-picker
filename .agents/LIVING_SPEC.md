# Living Spec: Trip Guide Web Application (trip/index.html)

## 1. 개요 및 목적
- **목적:** 천안·세종 2박 3일 가족 여행 일정 및 숙소 배정 현황을 안내하는 모바일 최적화 웹 가이드
- **대상:** 어르신(전영환 어르신 외), 성인, 어린이 포함 온 가족 9명 (야외/이동 중 모바일 시인성 극대화)
- **경로:** `trip/index.html`
- **구조:** 단일 HTML 파일 (Vanilla CSS + HTML5 + 순수 JS)

## 2. 디자인 시스템 (Modern Clean High-Contrast UI)
- **배경:** `#f1f5f9` (소프트 슬레이트 백그라운드로 눈부심 방지)
- **카드 표면:** `#ffffff` (순백색 고대비 카드 + 1px `#e2e8f0` 경계선 + 소프트 엘레베이션 그림자)
- **타이포그래피 및 가독성:**
  - 기본 본문: `16px`, 행간 `1.6`
  - 메인 텍스트: `#0f172a` (최고 등급 명도 대비 확보)
  - 보조 텍스트: `#475569`
  - 제목 크기: H1 `1.85rem`, 섹션 타이틀 `1.25rem`, 스텝 타이틀 `1.15rem`
- **시각적 요소:**
  - **탭 네비게이션:** 터치 타겟 확대(높이 및 패딩 확보), 활성 탭에 솔리드 코발트 블루(`#2563eb`) 적용
  - **숙소 배정 카드:** 룸별 카드 배경 `#f8fafc` 분리, 연박/이동 태그 고대비 폰트 및 배경 적용
  - **타임라인:** 3px 선명한 트랙, 20px 직경의 굵은 핀 도트, 넉넉한 글자 간격
  - **열차 승차권 카드 (Ticket UI):** 코레일 승차권 모티브의 컴포넌트 (`1일차 ITX-마음 1011호`, `3일차 무궁화 1156호`). 열차명/열차번호 뱃지, 출·도착역, 발착 시간 및 총 소요시간을 직관적으로 시각화.
  - **하단 액션 버튼:** 큼직한 15px 패딩, 볼드 폰트로 원터치 조작성 강화

## 3. 인터랙션 & UX
- **탭 전환 스크롤 복귀:** 일차 탭(1일 차/2일 차/3일 차) 변경 시, 스크롤 위치에 관계없이 해당 일차의 `day-header-box`(일차 헤더 요약 박스) 위치로 부드럽게(`smooth`) 자동 이동 (상단 Sticky 탭 높이 보정).
